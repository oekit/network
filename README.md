## 安装

```bash
go get github.com/oekit/network@v0.2.6
```

## 这个仓库做什么

`network` 是**轻量网络客户端集**：WebSocket 广播、NATS、消息队列抽象、连接与流工具、
Octopus 推送。与 [httpx](https://github.com/oekit/httpx) 的区别：这里的东西**不强制**
服务发现/熔断那套重语义，只要轻量通信就到这里来。

## 组成

| 包 | 做什么 |
|---|---|
| `wsutil` | WebSocket 广播器：房间注册、背压安全（慢连接超时跳过不拖死循环） |
| `nats` | NATS 客户端（嵌入式测试友好） |
| `mq` | 消息队列抽象 |
| `conn` | 连接管理 |
| `streamx` | 流工具 |
| `octopus` | Octopus 推送客户端 |

## 快速使用

```go
import "github.com/oekit/network/wsutil"

b := wsutil.NewBroadcaster()
b.Register("room:1", conn)
b.Broadcast("room:1", []byte("hello")) // 慢消费者超时跳过，不阻塞其他连接
```

## 边界
